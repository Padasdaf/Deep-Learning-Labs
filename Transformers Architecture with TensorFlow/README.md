# Transformers Architecture with TensorFlow
I implemented key components of the Transformer model using TensorFlow 2.4. I created positional encodings, computed scaled dot-product attention, and implemented multi-head attention. I also built the encoder and decoder layers, then combined them to form a complete Transformer model. This architecture speeds up training and improves performance for tasks like language translation. Using the provided Coursera starter notebook, I followed the structure and utilized helper functions to guide me through the process of building and understanding Transformer models in NLP.
